# نظام المبيعات غزل — v6.7

## تعديلات هذه النسخة

- واجهة الحقول والنوافذ عادت عربية بالكامل.
- أي أرقام يكتبها المستخدم بالأرقام العربية أو الفارسية تتحول تلقائياً إلى الأرقام الإنجليزية 0-9 بدون تغيير النص العربي.
- الحقول الرقمية وكود الصنف تعرض الأرقام باتجاه LTR وبلغة en-US.
- في صفحة المبيعات زر فلترة بجانب «فاتورة مبيعات جديدة».
- فلاتر التاريخ: الكل، آخر يوم، آخر أسبوع، آخر شهر، آخر سنة، تاريخ محدد، ومن تاريخ إلى تاريخ.
- فلترة مستقلة حسب كود الصنف للمساعدة في الوصول إلى الفواتير وتصحيح صنف مسجل بالخطأ.
- الفلترة السحابية تستخدم استعلاماً مباشراً محدوداً بالصفحة بدل تنزيل كل المبيعات.
- عند عدم توفر الإنترنت تعمل الفلترة على البيانات الموجودة في IndexedDB.
- التنقل السابق/التالي يستمر داخل نتائج الفلترة.
- الشريط السفلي يبقى مخفياً على اللابتوب والكمبيوتر (821px فأكثر).
- تم تحديث Service Worker إلى كاش جديد.


## v6.8 — المخزن الكلاسيكي
- إعادة شاشة المخزن إلى تصميم أول نسخة غزل: أعمدة ملونة، إجمالي أعلى الجدول، وصف إجمالي لكل فئة.
- الحسابات والمزامنة وتعديل/حذف البيانات بقيت من آخر نسخة.
- تم تحديث كاش PWA للإصدار الجديد.
