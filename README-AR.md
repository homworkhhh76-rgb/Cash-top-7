# نظام المبيعات متعدد الشركات — Turso Direct v6

هذه النسخة تتصل مباشرة بقاعدة Turso من المتصفح بدون Worker وبدون Vercel وبدون Firebase.

## قاعدة البيانات
- Turso database: `libsql://cash-top-homworkhhh76-rgb.aws-eu-west-1.turso.io`
- الاتصال يتم إلى `/v2/pipeline` مباشرة من `cash-top-cloud.js`.
- تم أخذ بيانات الاتصال من ملف CashTop المباشر الذي زوده المستخدم.
- بيانات هذا النظام معزولة في جدول: `general_sales_kv_v6`.

## التشغيل
كل الملفات في مستوى واحد. افتح `index.html` للتطبيق و`admin.html` لإدارة الشركات. للتثبيت كـ PWA استخدم HTTPS أو localhost.

## الأدمن
كلمة المرور الافتراضية لأول تشغيل: `78789852`. أول دخول يحفظ Hash كلمة المرور داخل جدول النظام في Turso، ويمكن تغييرها من لوحة الأدمن.

## الشركات والموظفون
الأدمن ينشئ شركة ويحدد مدة المفتاح. دخول الشركة يتم بواسطة مفتاح الشركة + اسم المستخدم + كلمة المرور. قسم المستخدمين يتيح موظفين وصلاحيات دقيقة. انتهاء المفتاح أو إيقاف/حذف الشركة يمنع التحقق السحابي ويعيد المستخدم لتسجيل الدخول عند أول اتصال.

## الأوفلاين والمزامنة
البيانات تُحفظ Local-First في IndexedDB. طابور المزامنة دائم ولا تتوقف بقية العمليات عند فشل عملية منفردة. الواجهة تعمل من Service Worker بعد أول تحميل.

## تنبيه أمني
هذه نسخة Turso Direct حسب طلب المستخدم. رمز Turso موجود داخل JavaScript ويمكن لمن يحصل على ملفات الموقع رؤيته واستعمال صلاحياته.


## تحديث 6.1 — دخول الأدمن المحلي
- دخول لوحة الأدمن محلي بالكامل ولا ينتظر قاعدة البيانات.
- كلمة المرور الافتراضية: `78789852`.
- تغيير كلمة مرور الأدمن يحفظها على نفس الجهاز/المتصفح فقط ولا يكتبها في قاعدة البيانات.
- بعد الدخول، تحميل الشركات يتم بشكل مستقل؛ تعطل الاتصال لا يمنع فتح لوحة الأدمن ولا يعلق زر الدخول.
- طلبات قاعدة البيانات المباشرة لها مهلة 15 ثانية حتى لا تبقى الأزرار في حالة انتظار بلا نهاية.
